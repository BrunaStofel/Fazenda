## Documentação do projeto

A documentação está organizada em arquivos `.md` na raiz do projeto:

- [DOC.md](DOC.md)  
  Visão geral funcional do aplicativo:
  - Objetivo do sistema.
  - Conceitos principais (talhão, custo).
  - Fluxos básicos de uso pelo produtor.

- [FEATURES.md](FEATURES.md)  
  Detalhamento das funcionalidades (features) do app:
  - Listagem e cadastro de talhões.
  - Tela de detalhe do talhão e listagem de custos.
  - Cadastro de custos por talhão.
  - Funcionalidades futuras (login, captura de nota fiscal por foto).
  Define comportamento esperado da UI e integração com o backend.

- [ARCHITETURE.md](ARCHITETURE.md)  
  Padrões de arquitetura e boas práticas em Flutter:
  - Organização de pastas (feature-first + camadas Domain/Data/Presentation).
  - Padrão de arquitetura adotado (Clean Architecture simplificada).
  - Boas práticas de estado, comunicação com backend, modelos, testes e navegação.
